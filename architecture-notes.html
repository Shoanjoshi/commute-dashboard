What It Took to Build

Accounts, credentials, and services behind the Commute Dashboard

Accounts & Services Required
🐙
GitHub Free
Stores all the code and hosts the dashboard as a live website — no server needed. Anyone with the link can open it.
☁️
Cloudflare Free tier
Runs the secure data relay in the cloud. Keeps all API keys hidden from the public and safely fetches live data on the dashboard's behalf.
🗺️
Google Cloud Console API Key
Provides access to Google Maps' live traffic data — used to calculate real-time drive time from home to the train station.
🚆
NJ Transit Developer Portal Username & Password
Grants access to NJ Transit's real-time train departure API — the source for live train status, track numbers, and delays.
🤖
Anthropic (Claude AI) API Key Backup only
Used as a fallback if the data relay is unavailable — Claude can estimate commute conditions when live APIs can't be reached.
How They Connect
1
Code lives on GitHub. GitHub Pages turns it into a public website instantly — no hosting bill, no server to manage.
2
API keys are stored inside Cloudflare — not in the code. This means they're never visible to anyone who views the page.
3
On every refresh, the dashboard calls the Cloudflare relay. The relay uses the stored keys to query Google Maps and NJ Transit simultaneously.
4
Results are assembled and returned in seconds — train status, drive time, and alerts all appear on the same screen.
5
If the relay is ever unreachable, Claude steps in as a backup and estimates conditions based on the latest available information.
Nothing is stored or logged — every refresh is a fresh, live fetch.
All credentials are held by their respective platforms, not in the codebase.
